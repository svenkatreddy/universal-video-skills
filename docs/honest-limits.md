# Honest Limits

What this skill pack does not do, so nobody is surprised later.

**It doesn't generate video.** These are prompting, planning, and
production skills for AI agents. The actual generation happens in whatever
video tool you use — the adapters help you talk to it, but there's no API
key hidden in here.

**It can't make a model do what the model can't do.** Readable on-screen
text, perfect lip sync, complex multi-object physics — these are still hard
for every generator. The skills teach you to design around the limits, not
to prompt through them.

**Model specs go stale.** Durations, resolutions, prices, and feature lists
change every few months. Every adapter sheet is dated; if the date is old,
verify against the provider before you plan around a number. Stale specs
are worse than no specs, so we'd rather you check than trust us.

**The adapters are prompting knowledge, not integrations.** They tell you
how each model likes to be talked to. They don't call APIs, manage keys, or
track your usage.

**Taste is still yours.** The pack gives you craft: grammar, structure,
checklists, vocabularies. It doesn't give you ideas, and it won't tell you
whether your story is any good. That's the part no skill can do.

**English only.** The pack is written in English, for English prompting.
Prompting in other languages works, but the examples, idioms, and TTS notes
assume English. Contributions in other languages are welcome (see
CONTRIBUTING.md) but the core stays English-first.

If any of this is a dealbreaker, the pack isn't for you — and we'd rather
you know that here than after installing it.
