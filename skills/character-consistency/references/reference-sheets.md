# Reference Sheets

One sheet per asset. Physical, specific, and frozen. This is the text that
gets pasted verbatim into prompts, so write it like a spec, not a story.

## Character sheet template

```
## mara-01

Face: 34, sharp jawline, straight nose, dark brown eyes, no glasses.
Hair: copper-red bob, straight, jaw-length, side part on the left.
Build: 5'7", lean, long stride.
Wardrobe (default): olive bomber jacket, black t-shirt, dark jeans, worn
  white sneakers. Small silver hoop earrings.
Distinguishing: faint scar through the left eyebrow.
Never: long hair, different jacket color, heavy makeup.
```

Notice: no personality, no backstory, no mood. The sheet answers "what does
she look like, standing still, in neutral light." Everything else (wet hair,
torn sleeve, terrified expression) belongs in the shot-brief, because it
changes per shot.

## Product sheet template

```
## bottle-apex-01

Matte black 500ml bottle, cylindrical, 24cm tall. Label: cream band,
  "APEX" in charcoal sans-serif, centered, no other text. Cap: brushed steel.
Never: glossy finish, visible logo variations, condensation (unless briefed).
```

Geometry, materials, label text and placement, scale cues. "The thing being
sold" deserves the same rigor as a face. Audiences spot product drift
instantly.

## Writing rules

- **Observable facts only.** If a camera can't see it, it doesn't go on the
  sheet.
- **Name the never-list.** The three or four things the model will wrongly
  invent (long hair, glossy finish) get banned explicitly. This is cheap
  insurance.
- **One wardrobe default.** Characters can change clothes mid-story, but the
  sheet holds the default and changes get versioned (`mara-02`), not edited
  in place.
- **Keep it short enough to paste.** If the sheet is a page long, nobody
  pastes it and the discipline dies. Aim for under 120 words per asset.
- **Freeze it at Gate 3.** After the asset lock, the sheet changes only by
  version bump, with a note saying why.
