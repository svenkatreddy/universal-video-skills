# Adapter Template

Copy this file for a new model. Keep it to one page. Date everything
perishable.

```markdown
# <Model> (Adapter)

_Last verified: YYYY-MM-DD. Specs change — recheck before planning._

## In one line

What this model is for, in a sentence. Its reputation among people who
actually use it.

## Prompt quirks

- How it likes prompts phrased (prose vs. structured, keyword order,
  anything the community has learned).
- Negative prompt: separate field? Inline only? Ignored?
- Reference images: supported? How many? How much weight do they carry?

## Hard limits

- Max duration, resolutions, aspect ratios. (Verify — these move.)
- Anything it flat-out can't do (text, dialogue, etc.).

## Good at / weak at

- 2–3 things it does better than average.
- 2–3 things to design around.

## Translating a shot-brief

Concrete deltas: what to add, drop, or rephrase when moving a finished
brief onto this model. Examples beat generalities.
```
